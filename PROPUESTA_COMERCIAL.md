# Propuesta — Sistema de reservas y check-in para el Kartódromo de Zárate

## El problema

Hoy los turnos se gestionan con un sistema que **se llena al instante** y deja
clientes afuera. Cuando alguien **cancela**, ese lugar **queda vacío** (plata que
se pierde) porque no hay forma rápida de avisarle al siguiente interesado.
Además, al llegar, cada cliente **completa datos y firma papeles a mano**, lo que
genera filas, errores y trabajo administrativo.

## La solución

Una plataforma **propia del kartódromo** (web + WhatsApp) que funciona **al lado**
del sistema actual, sin reemplazarlo, y suma tres cosas que hoy no existen:

1. **Lista de espera inteligente con aviso por WhatsApp.** El cliente se anota; al
   liberarse un turno por una cancelación, el sistema le **avisa automáticamente**
   y lo reserva. Se vende lo que hoy queda vacío.
2. **Check-in digital sin papeles.** El cliente carga sus datos una vez y **firma
   el deslinde online**. Llega, muestra un **QR** y sube al kart.
3. **Panel de gestión** con métricas en vivo, base de datos de clientes y
   exportación a Excel.

## Beneficios concretos para el kartódromo

- 💰 **Recupera ingresos** de cancelaciones que hoy se pierden.
- ⏱️ **Menos trabajo en mostrador**: sin planillas ni firmas en papel.
- 🛡️ **Respaldo legal**: deslinde firmado y guardado digitalmente (Ley 25.326).
- 📋 **Base de datos de clientes** para promociones y recontacto.
- 📲 **Comunicación por WhatsApp**, el canal que el cliente ya usa.
- 🏁 **Imagen más profesional**: web propia con la marca del kartódromo.

## El número que importa

Un turno grupal vale aproximadamente **ARS 150.000 – 300.000**.
Recuperando apenas **4 a 8 cancelaciones por mes**, el sistema genera:

> **ARS 600.000 – 2.400.000 por mes** que hoy se están perdiendo.

El costo del sistema es **una fracción** de eso.

## Cómo funciona (para el cliente)

1. Carga sus datos y **firma** el deslinde (una sola vez).
2. Se **anota** en la lista de espera del día/horario que quiere.
3. Recibe el **aviso por WhatsApp** al liberarse el turno y confirma con un “SÍ”.
4. Recibe un **recordatorio el día antes** y hace **check-in con QR** al llegar.

recuperados**. Con esos números a la vista, el abono se justifica solo.
