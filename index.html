Negocios reales (Google Places)

Con una clave de Google, «Buscar negocios» trae negocios reales de Google Maps: nombre, teléfono, reseñas, web y horario. La clave queda guardada solo en tu navegador. En modo real no se inventa nada: lo que no se sabe, no se afirma en la ficha ni en el mensaje.

  1. Entrá a console.cloud.google.com y creá un proyecto.
  2. En «APIs y servicios», habilitá Places API (New).
  3. En «Credenciales», creá una clave de API y pegala acá.
  4. Elegí «Google Places» como fuente y guardá.

Tené en cuenta: Google pide tarjeta y cobra por uso pasada la capa gratuita mensual. Y la vista previa de claude.ai bloquea conexiones externas, así que para usar datos reales abrí el archivo index.html descargado en tu navegador.

Envío automático (WhatsApp Cloud API)

Con la API oficial de Meta, la campaña se manda sola: un botón y salen todos los mensajes, sin abrir WhatsApp ni confirmar uno por uno. Es el único método que no arriesga el bloqueo del número, porque es el canal oficial.

Cómo activarlo (una sola vez)

  1. Entrá a developers.facebook.com, creá una app de tipo «Empresa» y agregale el producto WhatsApp.
  2. En «WhatsApp → Configuración de la API» vas a ver el Phone Number ID y un token de prueba. Copiá ambos acá arriba.
  3. En «WhatsApp → Plantillas de mensajes», creá una plantilla de categoría Marketing con el texto que está más abajo y esperá la aprobación de Meta (suele tardar unos minutos).
  4. Poné el nombre de esa plantilla en el campo de arriba y tocá «Probar conexión».

Meta exige que el primer mensaje a alguien que nunca te escribió use una plantilla aprobada. Por eso el envío automático usa la plantilla y no el texto libre. Cuando el negocio responde, se abre una ventana de 24 horas en la que ya podés escribir lo que quieras.

La plantilla, lista para copiar

Pegala tal cual en el creador de plantillas de Meta. Las variables se completan solas con los datos de cada negocio.

El relay solo hace falta si al probar la conexión aparece un error de bloqueo del navegador (CORS). Es un archivo que se pega en un Cloudflare Worker gratuito y queda andando en dos minutos; también mantiene el token fuera de la página.
